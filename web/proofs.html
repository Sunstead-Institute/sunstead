Check a proof without trusting Sunstead

verify.py is one standard-library Python file (source and tests). Give it a proof id from this page and it clones the upstream repository from GitHub at the pinned commit, checks that the upstream statement is exactly the one the proof was checked against, puts the proof in place of the upstream sorry, builds it with the project's own Lean toolchain and lists the theorem's axioms (only propext, Classical.choice and Quot.sound pass). 

curl -fsSLO https://sunstead.org/verify.py
python3 verify.py <proof id>

When it passes, what you trusted is the upstream repository at that commit, GitHub for serving it, and the Lean toolchain elan installs for it. Sunstead's verifier, hub and code are not involved: the hub only hands over the candidate proof, and the script checks it hashes to the id you asked for. Building Lean runs code (tactics, and the upstream lakefile), so use a disposable VM or container if you would not build that upstream project directly. Needs git and elan; projects built on Mathlib download several GB of cache.
